# 🎤 Anu Voice Assistant

Anu is a Malayalam voice-activated intelligent assistant built using deep learning and speech processing techniques.

## 🚀 Features

* Wake word detection ("Anu")
* Malayalam command recognition
* Hybrid intent + entity system
* Application control (browser, calculator)
* Screenshot capture
* Modern animated UI

## 🧠 Tech Stack

* Python
* TensorFlow (CNN + MFCC)
* Librosa
* SpeechRecognition
* Tkinter

## 📌 Commands Supported

* open browser
* close browser
* open calculator
* screenshot
* play / pause / mute / unmute
* sleep / help

## ▶️ Run Project

```bash
pip install -r requirements.txt
python scripts/anu_app.py
```
